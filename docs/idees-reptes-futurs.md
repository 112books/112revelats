# Idees per a reptes futurs

## Cul
La cara oculta del retrat. Explorar el que el retrat convencional no mostra: l'esquena, el gest amagat, allò que queda fora del marc.

## Half
Combinació de fotografies fetes amb càmeres de mig format (half-frame). Cada fotograma ocupa la meitat d'un negatiu estàndard; el resultat final combina dues imatges en una sola.
